# KDAG Web - Frontend

Simple React + Vite + Tailwind with `axios` and `lucide-react`.

Quick start:

```bash
npm install
npm run dev
```

- package.json
- vite.config.js
- tailwind.config.cjs
- postcss.config.cjs
- index.html
- src/main.jsx
- src/index.css
- src/App.jsx
- src/components/Header.jsx
- src/components/Footer.jsx
- src/pages/Home.jsx
- src/pages/Items.jsx
- src/assets/logo.svg

Notes:
- Install dependencies with `npm install` then `npm run dev` to run the dev server.
- This project uses a simple client-side page switch (no router) via `App` state.
